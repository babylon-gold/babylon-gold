# Babylon AI Gold Intelligence — دليل تنزيل الشموع التاريخية
## المزود: Twelve Data — الخطة المجانية (Basic)

السكربت `twelvedata_downloader.py` ينزّل شموع **XAU/USD** التاريخية بأربعة أطر
(5min / 15min / 1h / 4h)، ثم يفحص جودتها ويكتب تقريرًا عربيًا.

السكربت **لا يتداول ولا يتصل بأي وسيط ولا ينفذ أوامر** — تنزيل بيانات وتحقق فقط.

---

## 1) أين تضع الملفات؟

انسخ الملفين (`twelvedata_downloader.py` و`README_TWELVEDATA_AR.md`) إلى مجلد المشروع. المكان المقترح:

```
D:\BabylonAI_GoldIntelligence\backend\data_ingestion\
```

(يصلح أيضًا جذر المشروع.) السكربت ينشئ مجلد `data\` بجانبه ويحفظ فيه كل النتائج.

## 2) المتطلبات

- Python 3.10 أو أحدث.
- مكتبة واحدة فقط:

```
pip install requests
```

## 3) مفتاح API — مهم جدًا

1. أنشئ حسابًا مجانيًا في **twelvedata.com** واحصل على **API Key** من لوحة التحكم.
2. ضع المفتاح بإحدى طريقتين:

**الطريقة الأولى (المفضلة): متغير بيئة في PowerShell**

```powershell
setx TWELVEDATA_API_KEY "ضع_المفتاح_هنا"
```

ثم **أغلق النافذة وافتح نافذة PowerShell جديدة** حتى يُقرأ المتغير.

**الطريقة الثانية:** أنشئ ملفًا باسم `api_key.txt` بجانب السكربت، وضع المفتاح وحده داخله.

> **قواعد الأمان:**
> - أضف `api_key.txt` و`data/` إلى ملف `.gitignore` حتى لا يُرفعا إلى Git.
> - لا تلصق المفتاح أبدًا في أي محادثة أو كود منشور أو لقطة شاشة.

## 4) التشغيل

```powershell
cd D:\BabylonAI_GoldIntelligence\backend\data_ingestion
python twelvedata_downloader.py
```

ما الذي سيحدث؟

1. **فحص الخطة:** يتأكد أولًا أن XAU/USD متاح على خطتك لكل إطار (4 طلبات فحص).
   إن لم يكن متاحًا، يخبرك بوضوح بدل أن يفشل بصمت.
2. **التنزيل:** دفعات حتى 5000 شمعة للطلب الواحد، مع التزام صارم بحد 8 طلبات/دقيقة —
   لذلك يستغرق التشغيل الكامل عادة **3–6 دقائق**، ويستهلك تقريبًا
   **15–25 طلبًا من أصل 800** متاحة يوميًا على الخطة المجانية.
3. **التحقق والتقرير:** فحص تسلسل الأوقات، والفجوات، وسلامة OHLC، والمكررات.

## 5) المخرجات

| الملف | المحتوى |
|---|---|
| `data\xauusd_5min.csv` | شموع 5 دقائق (المستهدف ~3 أشهر) |
| `data\xauusd_15min.csv` | شموع 15 دقيقة (المستهدف ~سنة) |
| `data\xauusd_1h.csv` | شموع ساعة (المستهدف ~3 سنوات) |
| `data\xauusd_4h.csv` | شموع 4 ساعات (المستهدف ~5 سنوات) |
| `data\validation_report_ar.md` | تقرير التحقق بالعربية |

- الأعمدة: `datetime_utc, open, high, low, close, volume` — **التوقيت UTC دائمًا**
  (قاعدة البيانات تبقى UTC، والواجهة تحوّل لاحقًا إلى توقيت بغداد).
- يمكن تعديل الأعماق المستهدفة من قائمة `TARGETS` في أعلى السكربت.

## 6) كيف تقرأ تقرير التحقق؟

- **فجوات نهاية الأسبوع:** طبيعية تمامًا — الذهب يغلق مساء الجمعة ويفتح مساء الأحد (UTC).
- **فجوات قصيرة (≤ ساعتين ونصف):** غالبًا فترة الصيانة اليومية أو سيولة منخفضة.
- **فجوات غير مبررة أو مخالفات OHLC:** راجعها قبل استخدام الملف في التحليل.
- عمود `volume` قد يكون فارغًا — حجم التداول لا يُنشر عادة للذهب الفوري،
  وسيُغطى لاحقًا ببيانات عقود GC من CME كمؤشر تأكيد منفصل (كما في تصميم النظام).
- قد يكون العمق الفعلي المتاح على الخطة المجانية **أقل من المستهدف**؛
  التقرير يُظهر المدى الحقيقي الذي وصل إليه كل إطار.

## 7) إذا ظهرت رسالة «غير متاح في خطتك»

بعض الرموز أو الأطر قد تتطلب خطة أعلى من Basic. البديلان المجانيان:

1. **MetaTrader 5 + حساب تجريبي:** مكتبة `MetaTrader5` في Python على Windows
   تسحب شموع XAUUSD بجميع الأطر مباشرة من الوسيط.
2. **Dukascopy:** بيانات تاريخية عميقة مجانية (حتى مستوى التيك) تحتاج تنزيلًا وتجميعًا إلى شموع.

أخبرني أيهما اخترت، وأجهّز لك سكربتًا بديلًا يُخرج **نفس صيغة CSV بالضبط** —
فلا يتغير شيء في بقية مكونات Babylon AI.

## 8) الخطوة التالية بعد نجاح التنزيل

ربط ملفات CSV بمحرك المؤشرات (EMA 20/50/200، RSI، ATR، ADX، بنية السوق،
Market Regime Detection) بدل الشموع التجريبية، مع إبقاء التمييز واضحًا في الواجهة:
**بيانات تاريخية حقيقية ≠ بيانات مباشرة.**
