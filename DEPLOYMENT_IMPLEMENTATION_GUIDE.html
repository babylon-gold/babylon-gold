Complete Cloud Deployment Implementation Guide

Phase 1: Local Docker Testing (5 minutes)

Test the complete stack locally before deploying to cloud environments.

1 Prerequisites

Install Docker Desktop from docker.com

2 Clone & Setup 
git clone https://github.com/yourname/babylon-gold.git
cd babylon-gold
cp .env.example .env
nano .env  # Edit with your settings
3 Start Services 
docker-compose up --build

# Services will be available at:
# Frontend: http://localhost:3000
# Backend: http://localhost:8000
4 Verify 
# Check backend health
curl http://localhost:8000/health

# View logs
docker-compose logs -f backend

# Stop when done
docker-compose down
✅ Success indicator: Both frontend and backend load without errors

Phase 2: Frontend Deployment to Vercel (5 minutes)

Deploy Next.js frontend to Vercel (recommended for Next.js projects).

1 Prepare GitHub Repository 
git init
git add .
git commit -m "Initial commit: Babylon AI"
git remote add origin https://github.com/yourname/babylon-gold.git
git push -u origin main
2 Connect to Vercel
  • Go to vercel.com
  • Sign in with GitHub
  • Click "Add New Project"
  • Select your repository
  • Set Root Directory: frontend
  • Build Command: npm run build
  • Output Directory: .next
3 Add Environment Variables

In Vercel Dashboard → Settings → Environment Variables:

NEXT_PUBLIC_API_URL=https://your-railway-backend.railway.app/api/v1
4 Deploy 
npm install -g vercel
cd frontend
vercel --prod

Your frontend URL: https://babylon-gold.vercel.app

✅ Success indicator: Frontend loads at vercel.app URL

Phase 3: Backend Deployment to Railway (5 minutes)

Deploy FastAPI backend to Railway.

1 Create Railway Account
  • Go to railway.app
  • Sign in with GitHub
  • Click "New Project"
  • Select "Deploy from GitHub repo"
2 Configure Deployment
  • Select your babylon-gold repository
  • Set Dockerfile: Dockerfile.backend
  • Set Port: 8000
  • Health Check: /health
3 Set Environment Variables

In Railway Dashboard → Services → Settings:

TELEGRAM_BOT_TOKEN=your_bot_token
TELEGRAM_CHAT_ID=your_chat_id
ENVIRONMENT=production
4 Deploy 
npm install -g @railway/cli
railway login
railway init
railway up

Your API URL: https://babylon-gold-api-production.railway.app

✅ Success indicator: curl https://your-railway-url/health returns 200

Phase 4: Connect Frontend to Backend (2 minutes)

Link the deployed services together.

1 Update Frontend API URL
  • Go to Vercel Dashboard
  • Settings → Environment Variables
  • Update NEXT_PUBLIC_API_URL
  • Value: https://your-railway-backend-url/api/v1
2 Redeploy Frontend 
cd frontend
vercel --prod
✅ Success indicator: Dashboard loads data from production API

Phase 5: Verification & Testing (5 minutes)

Verify all systems are working correctly.

1 Test Frontend 
curl https://babylon-gold.vercel.app
# Should return HTML page
2 Test Backend Health 
curl https://your-railway-backend.railway.app/health
# Should return: {"status": "healthy", ...}
3 Test API Connectivity 
curl https://your-railway-backend.railway.app/api/v1/admin/system/health-detailed
# Should return detailed health information
✅ All Systems Live! Your platform is in production

📋 Required Environment Variables

Backend (.env) - Railway

TELEGRAM_BOT_TOKEN=your_token_from_botfather
TELEGRAM_CHAT_ID=your_telegram_chat_id
ENVIRONMENT=production
DEBUG=false
ALLOWED_ORIGINS=https://babylon-gold.vercel.app,https://babylongold.com

Frontend (.env.local) - Vercel

NEXT_PUBLIC_API_URL=https://your-railway-url/api/v1
NEXT_PUBLIC_APP_NAME=Babylon AI
NEXT_PUBLIC_ENABLE_NOTIFICATIONS=true

GitHub Secrets (for CI/CD)

VERCEL_TOKEN=from_vercel_settings
VERCEL_ORG_ID=your_org_id
VERCEL_PROJECT_ID=your_project_id
RAILWAY_TOKEN_PRODUCTION=from_railway_tokens

Vercel Monitoring

Railway Monitoring

  • Dashboard: railway.app
  • Logs: railway logs -f
  • Metrics: CPU, Memory, Network visible in service dashboard

Health Checks

# Daily health check
curl https://your-api.railway.app/health

# Detailed system health
curl https://your-api.railway.app/api/v1/admin/system/health-detailed

🐛 Troubleshooting Common Issues

Issue Solution
Frontend can't reach API Update NEXT_PUBLIC_API_URL in Vercel environment variables
CORS errors Check backend ALLOWED_ORIGINS includes your Vercel domain
Telegram notifications not working Verify TELEGRAM_BOT_TOKEN and TELEGRAM_CHAT_ID
Build fails on Vercel Run npm run build locally to debug
Backend deployment fails Check Railway logs: railway logs -f
